## 证据（做完怎么证明）

证据必须在**本次**执行产生。

- 纯样式 / 静态页 → `dev` 起服务 + 目标页截图
- 组件交互 → 单测输出，或手动路径复现步骤
- 路由 / 接口 → 实际请求一次：状态码 + 返回形状 + **不该出现的字段是否出现**
- 数据层 / schema → 迁移 dry-run + 一次写入再读回
- 依赖 / 构建 → `build` 通过（含警告）
- 上线 → 3 条冒烟：首页 / 主流程 / 关键接口

接缝越靠上越好：接口响应 > 数据层 > 页面渲染。一次改动需要 3 个以上接缝才能证明，说明范围没切好。
